# 详情页样式

下载书籍和微信读书共用封面、标题、轻量标签、简介和出版信息样式，正文直接承接封面背景。参考灵沐的连续内容分区，沿用 Olib 的主题配色和现有 Flutter 控件。

- Z 站和微信读书详情页共用立体封面：默认正面朝向读者，以书脊、纸页边缘、封面反光和随旋转角度变化的柔和阴影表现厚度；拖动封面可以旋转，双击回到正面。封面背景使用深色舞台并在底部渐变接入正文；滚动收起后导航栏显示书名。系统要求减少动画时停止自动微动。
- 书名和作者左对齐；格式、大小、年份或分类、评分使用轻量标签。出版社、页数、语言或 ISBN 移入出版信息。
- 简介默认最多六行；只有实际超出六行时提供展开与收起，更换内容会重置展开状态。
- 微信读书详情页把作者、分类、评分、出版社、出版时间与 ISBN 收在同一书籍信息区。个人划线和想法默认各展示两条，目录默认展示四章，仍可展开全部。
- 热门划线以横向卡片浏览；公开点评使用单个星级下拉菜单（5 星到 1 星），只显示所选星级的横向卡片。卡片可打开全文，点评可按需继续加载；存在未评分点评时在菜单中追加该选项。
- 底部预览与下载操作保留原有流程，使用最小高度 48 的按钮，容许大字体增加高度。收藏操作等待返回结果，失败时显示提示，避免重复提交。

没有新增依赖或修改 API。相关组件测试位于 `test/widgets/book_detail_test.dart`，覆盖长简介、窄屏、大字体、深浅主题、滚动标题、目录展开和下载按钮状态。

首页 z站 推荐接口只返回书籍摘要（ID、hash、标题、作者、封面）。打开详情页时按需调用 `/eapi/book/{id}/{hash}` 补全简介、格式与 `readOnlineUrl`，接口返回预览地址时显示预览入口；请求失败时保留摘要并提供重试。切换线路会清除已缓存的详情。

Litera 预览页默认关闭逐资源探针，也不再拦截 Android WebView 的每个请求。需要定位加载耗时时，可用 `flutter run --dart-define=LITERA_PROBE=true` 临时开启资源耗时日志与导出入口；日志仅保留域名和脱敏路由，不包含查询参数、片段、账号标识或请求头。资源总耗时只能说明该资源完成得慢，定位原因仍需结合浏览器网络面板的等待、下载阶段和不同线路的对比。

```powershell
flutter analyze --no-pub lib/screens/book_detail lib/screens/weread test/widgets/book_detail_test.dart
flutter test --no-pub test/widgets
```
