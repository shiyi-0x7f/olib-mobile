# 首页推荐卡片布局

首页推荐网格使用 `BookCard(compact: true)`，其他页面沿用默认布局。

- 保留原有按可用宽度分列的逻辑，列间距 16，行间距从 20 缩至 12。
- 首页采用纯封面书架：不使用模糊大背景，封面周围仅保留 4 像素的淡色背景。
- 外层圆角为 4，封面圆角为 2，阴影减弱，保持书籍的矩形轮廓。
- 以 0.7 的封面宽高比计算高度，使用 `BoxFit.contain` 完整显示封面。
- `BookCoverBackdrop` 负责封面的展示，不重复加载背景图片。
- 卡片不再显示书名、作者、评分和在读人数，完整信息在详情页查看；读屏仍能获取书名与作者。
- 首页卡片右上角显示来源图标和短文字，z站使用书库图标，微信读书使用微信图标；缺失封面时仍显示，读屏名称也包含来源。
- 卡片总高度由 `BookCard.compactHeightFor` 计算，不受系统字号影响。
- 缺失封面沿用现有占位，点击详情、推荐分页、加载 / 空 / 错误状态沿用原逻辑。

例如 400 逻辑像素宽的屏幕，两列卡片宽约 172，卡片高度约 242，低于原布局的约 277。

验证：`flutter test --no-pub test/widgets`。测试覆盖不同卡片宽度、1 / 1.5 / 2 倍字号、明暗主题、读屏名称、缺失封面、点击回调和默认卡片的标签显示。

运行应用直接查看实际效果，不导出预览截图。

## 应用图标

使用用户提供的 `assets/icons/olib-app-logo.png`。`pubspec.yaml` 中的 Android / iOS / Web / Windows / macOS 图标生成配置及 Windows MSIX 标识均引用该文件。Android 自适应背景使用 `#EAF1E9`。

更新源 PNG 后运行 `dart run flutter_launcher_icons` 重新生成各平台资源。SVG 保留作设计源文件，运行应用不需要 SVG 渲染依赖。
