# 收藏与本地下载

## 收藏页

- `unifiedShelfProvider` 汇总图书馆收藏和微信读书书架，不按当前来源过滤。界面单独筛选来源，因此来源计数基于完整已加载数据。
- 图书馆收藏使用 `getUserSaved(page, limit)` 分页加载。两个来源独立呈现加载错误；任一来源已加载的数据仍可浏览。
- 搜索、排序、网格/列表切换和来源/分类筛选仅改变当前页面展示，不修改远端收藏。
- 默认视图按响应式列数把真实藏书摆在连续木质层板上；搜索、筛选、分类和排序放在同一套书柜背板与侧框内，来源名称和数量只在上方筛选条显示。每本书的封面朝前，分类名称写在封面标签上，书名和作者显示在层板前缘。列表模式使用连续书柜背板与薄木层板，左侧展示立体小封面，右侧按书名、作者和横向状态标签排列。
- 用户分类保存在本机 Hive `settings` box 的 `shelf_categories_v1` 键中。一个书籍至多属于一个自定义分类，分类键采用 `library:<id>` 或 `weread:<id>`，避免两个来源的 ID 冲突。重命名保留归属；删除分类时，书籍变为未分类，不删除远端书籍。分类当前不会跨设备同步。
- 轻点书籍打开详情；长按图书馆书籍进入多选整理，选中状态由封面边框和缓慢呼吸的绿色光晕表示（系统关闭动画时保持静态光晕），底栏集中提供分类、批量移出收藏和分享书单。长按微信读书书籍显示继续阅读、归类和查看详情，不参与图书馆批量删除。书籍封面不显示常驻三点菜单。

## 本地下载页

- “进行中”包含准备、下载、失败和取消状态；“已完成”只包含有完成记录的任务。点击已完成书籍前再次检查文件是否存在，缺失时转为失败。
- 任务保存下载时间和实际文件大小供列表显示；既有历史记录从 `downloadTime` 和本地文件读取这些信息。
- 普通账号下载可在保留完整书籍信息时重试。使用一次性签名链接的下载需要回原书页重新获取链接；从历史恢复但文件缺失的记录只支持移除。
- 新下载先写入临时文件，成功后移到最终文件名；取消或失败后清理临时文件。删除已完成任务会删除设备上的文件和下载记录。
